# 🎥 yt-dlp Command Generator

<p align="center">
  <em>A sleek, 100% client-side Chrome Extension that visually builds complex yt-dlp terminal commands.</em>
</p>

---

## ⚡ Overview
**yt-dlp Command Generator** takes the headache out of memorizing hundreds of `yt-dlp` terminal flags. Instead of manually typing out format merges, timestamp extractions, and metadata embeddings, this extension provides a beautiful, modern UI right inside your browser to do the heavy lifting for you.

Because it operates entirely as a text generator, it is **Web Store Compliant** and strictly requires **Zero OS Integration** (no native messaging, no companion scripts, no registry edits). It just works.

## ✨ Features
- 🚀 **1-Click Command Copying:** Generates the exact `yt-dlp` syntax dynamically.
- 🎬 **Smart Mode Selection:** Easily switch between *Best Video + Audio*, *Custom Resolution*, *Extract Video Only*, and *Extract Audio Only*.
- ⏱️ **Timestamp Grabber:** Click "Grab ⏱️" to instantly pull the current video's timestamp directly from the active YouTube player.
- 💾 **State Persistence:** Automatically remembers your last used settings and format choices.
- 📂 **Auto-Detects Download Folder:** Intelligently reads your browser's last download location to auto-populate the output directory.
- ⚙️ **Advanced Flags:** Supports SponsorBlock removal, browser cookie passing, metadata embedding, subtitle extraction, geo-bypassing, and custom output templates.
- 💻 **Cross-Platform:** The generated commands work identically on macOS, Windows, and Linux.

## 🛠️ Installation (Developer Mode)

1. Clone or download this repository to your local machine:
   ```bash
   git clone https://github.com/mattjunior039/yt-dlp-cmd-generator.git
   ```
2. Open Google Chrome (or any Chromium browser like Edge/Brave) and navigate to `chrome://extensions/`.
3. Enable **Developer mode** in the top right corner.
4. Click **Load unpacked** and select the folder where you cloned this repository.
5. Pin the extension to your toolbar and you're good to go!

## 📦 Prerequisites
To actually run the commands generated by this extension, you must have `yt-dlp` and `FFmpeg` installed on your machine. 

*(A simple, copy-paste install guide for Mac, Windows, and Linux is bundled directly inside the extension! Just click "Install Guide" in the header.)*

## 🔒 Privacy & Security
This extension is completely sandboxed. It does not track you, it does not send analytics, and it does not connect to any external servers. The code runs entirely locally inside your browser to safely construct text commands.
