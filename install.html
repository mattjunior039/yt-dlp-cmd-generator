Installation Guide

To use the commands generated by this extension, you need to install yt-dlp and FFmpeg on your computer.

Important: FFmpeg is required for merging high-quality video and audio together, and for extracting audio files like MP3 or M4A. Do not skip installing it!

🍏 macOS

Step 1: Install Homebrew (If you don't have it)

Open Terminal (Press Cmd + Space, type "Terminal", and hit Enter). Copy and paste this command, then press Enter:
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"

Note: The Terminal might ask for your Mac password. It won't show characters as you type, just type it and press Enter.

Step 2: Install yt-dlp & FFmpeg

Once Homebrew is ready, paste this into your Terminal and hit Enter:
brew install yt-dlp ffmpeg

🪟 Windows

Open Command Prompt or PowerShell (Press the Windows Key, type "cmd", and hit Enter). Copy and paste this command:
winget install yt-dlp winget install gyan.ffmpeg

If Winget fails, you can download the .exe directly from GitHub.

🐧 Linux (Ubuntu/Debian)

Open your Terminal and paste these commands:
sudo wget https://github.com/yt-dlp/yt-dlp/releases/latest/download/yt-dlp -O /usr/local/bin/yt-dlp sudo chmod a+rx /usr/local/bin/yt-dlp sudo apt update && sudo apt install ffmpeg
