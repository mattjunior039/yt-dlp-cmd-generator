Installing yt-dlp and FFmpeg

To use the commands generated by this extension, you need to have yt-dlp and FFmpeg (for merging audio and video, extracting audio, etc.) installed on your system.

Note: FFmpeg is highly recommended! Without it, yt-dlp cannot combine 1080p+ video with audio, nor can it extract MP3/M4A files.

🍏 macOS

The easiest way to install on a Mac is using Homebrew.

brew install yt-dlp ffmpeg

🪟 Windows

You can use Winget (pre-installed on Windows 11 and modern Windows 10) or Scoop.

Using Winget:

winget install yt-dlp
winget install gyan.ffmpeg

Using Scoop:

scoop install yt-dlp ffmpeg

🐧 Linux (Ubuntu/Debian)

You can install it directly via apt, or use the official binary for the latest version.

Using APT:

sudo apt update
sudo apt install yt-dlp ffmpeg

Alternatively, downloading the latest binary:

sudo curl -L https://github.com/yt-dlp/yt-dlp/releases/latest/download/yt-dlp -o /usr/local/bin/yt-dlp
sudo chmod a+rx /usr/local/bin/yt-dlp
sudo apt install ffmpeg

Verification

After installing, restart your terminal and verify the installation by running:

yt-dlp --version
ffmpeg -version
